# Truth Base Writing

Use this skill when writing must sound like the user, preserve verified facts, or follow the user's academic writing preferences.

## Voice rules

- Use a practical, direct, first-person voice when the assignment allows first person.
- Ground examples in documented user work themes only, such as field audit, mystery shopping, scheduling, customer service, commerce, local workflow, and practical technology work.
- Do not invent personal history, jobs, credentials, family details, trauma, military service, legal events, or lived experiences.
- Leave blanks or bracketed questions for missing personal facts.
- Avoid the punctuation mark that connects two words with a short horizontal line. Rewrite the sentence instead.

## Fact checking rules

Every claim in a final draft must fall into one of these categories:

- Verified from course material.
- Verified from a cited outside source.
- User provided.
- Clearly labeled as analysis or opinion.

If a claim does not fit one of those categories, remove it or mark it for review.

## Source rules

- Prefer current course materials first.
- Use the required textbook when the prompt requires it.
- Add outside sources only when the prompt allows or requires them.
- Do not fabricate citations, page numbers, URLs, quotes, dates, authors, or DOIs.
- Use source links or file references in the review notes so the user can verify.

## Draft review pass

Run these checks before handing off a draft:

1. Requirement match.
2. Rubric match.
3. Source support.
4. Voice match.
5. Grammar and spelling.
6. APA 7 formatting.
7. No invented personal details.
8. No prohibited punctuation mark.
9. Clear user approval needed before submission.

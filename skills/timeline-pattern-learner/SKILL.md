# Timeline Pattern Learner

Use this skill when scheduling coursework automation around the user's real working pattern.

## What to track

- When assignments become available.
- When the user usually reviews drafts.
- Which days are best for discussion posts.
- Which days are best for replies.
- How long papers usually take.
- How early final drafts should be ready.
- How much safety buffer is needed before midnight deadlines.
- Repeated conflicts from work, appointments, or travel.

## Schedule rules

- Build in review time before submission time.
- Schedule source gathering before drafting.
- Schedule fact checking before APA polishing.
- Schedule final user approval before any upload.
- Keep emergency buffer time before official deadlines.

## Conflict handling

When a new deadline conflicts with the current plan:

1. Identify the conflict.
2. Move low risk drafting blocks first.
3. Preserve final review and approval blocks.
4. Notify the user when work becomes compressed.

## Learning behavior

After each week, compare planned timing against actual timing:

- What was early.
- What was late.
- What required user intervention.
- What took longer than expected.
- What should be scheduled earlier next week.

Use the next week to improve timing, but do not silently remove approval gates.

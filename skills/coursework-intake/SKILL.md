# Coursework Intake

Use this skill when the user asks Codex to review weekly coursework, build assignment outlines, or organize course materials from Blackboard, Google Drive, Gmail, Outlook, or local files.

## Required intake order

1. Identify the exact course, unit, assignment title, due date, point value, and source location.
2. Collect all available materials before drafting:
   - Assignment prompt.
   - Rubric.
   - Syllabus objective or weekly learning objective.
   - Required readings, videos, textbook references, and professor announcements.
   - Prior instructor feedback when available.
3. Save or reference source files in the user's student storage location when the connector is available.
   - Verify the storage account with live-account-connections before creating folders or uploading files.
   - Read back every created folder or uploaded file and retain the returned identifier.
4. Create a brief intake summary that separates:
   - Verified requirements.
   - Missing or unclear requirements.
   - Drafting assumptions.
   - Questions that need the user's decision.

## Academic integrity boundary

Codex may prepare outlines, checklists, study notes, citations, draft fragments, and review comments. Codex must not represent unreviewed AI writing as the user's final work, certify authorship, or submit to a school system without direct user review and approval.

## No-skip checklist

Before writing, confirm every item below is either found or marked missing:

- Course name.
- Unit or week.
- Assignment title.
- Due date and time.
- Submission location.
- Required source count.
- Required textbook or course source.
- Required outside source rules.
- Required word count or page count.
- Formatting style, especially APA 7.
- Rubric categories and point values.
- Special professor instructions.

## Output format

Return:

- A source inventory.
- A requirement checklist.
- A work plan.
- A file organization plan.
- Drafting questions only when needed.

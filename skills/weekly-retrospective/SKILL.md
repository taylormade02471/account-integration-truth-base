# Weekly Retrospective

Use this skill after a unit or week is completed.

## Review questions

- Were any deadlines changed?
- Did any assignment take longer than expected?
- Did the user correct the same issue more than once?
- Did a professor give feedback that should become a rule?
- Were any sources rejected or replaced?
- Did any APA issue repeat?
- Did the user approve the schedule or move work to a different time?

## Outputs

Create:

- Lessons learned.
- New or revised user rules.
- Schedule adjustments.
- Rubric risks for next week.
- Source preferences.
- Carryover tasks.

## Guardrail

Do not treat a single mistake as a permanent rule. Mark uncertain patterns as suggestions until the user confirms them.

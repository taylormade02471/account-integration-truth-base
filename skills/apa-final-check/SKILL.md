# APA Final Check

Use this skill for final review of written papers, assignments, discussion posts, replies, and school emails.

## Review sequence

1. Confirm the exact assignment requirements and rubric.
2. Check title, course, instructor, date, and student name fields if required.
3. Confirm APA 7 formatting expectations:
   - Title page when required.
   - Double spacing for papers when required.
   - 12 point Times New Roman when required.
   - Page numbers when required.
   - Reference page when sources are used.
   - In text citations aligned with reference entries.
4. Run spelling and grammar review.
5. Check that source claims are accurate and traceable.
6. Confirm the user's punctuation preference.
7. Produce a final readiness report.

## Final readiness report

Include:

- Pass or needs attention.
- What was checked.
- Any missing requirement.
- Any source or citation risk.
- Any formatting issue.
- Whether user review is still required before submission.

## Do not do

- Do not invent citations.
- Do not silently change assignment meaning.
- Do not remove rubric-required content to make prose smoother.
- Do not submit or certify the work for the user.
